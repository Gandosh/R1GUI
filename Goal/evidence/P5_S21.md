# Slice evidence: 5.21 Brush library popup, controller and gallery

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** High (a new overlay that takes over the keyboard, key flow through the global handler of several windows, widget lifetime across native windows)   **Review:** none yet (recommended before Phase 6)

## Built
`source/ui-widgets/{include/r1ui/widgets,src}/brushes/`:
- `BrushLibraryPopup`: one self-painting widget (search field and mode switch, category chips, virtualised tile grid with a Recent section and headers, quick letter badges with the typed prefix and the marked next letter, favourite star, accent outline for the active brush, footer with the key hints and the pick-on-unique option, scrollbar) plus the inline Assign letter popover and the tile menu. Every key and character belongs to it while it is open.
- `BrushLibraryController`: registers the command `brush.library` (default chord B, context global), opens the popup on the overlay layer of the window that had the key press (`tapKeys()` wraps each window's global key handler), centred on the pointer and kept inside the window, one library at a time, closes on Escape, a click outside, a pick, window deactivation, window destruction and its own destruction, restores focus, ignores the character and repeats of the opening key, closes on the opening chord under the rules of `docs/dev/brush-library.md` section 4.
- `BrushTileLayout` (private geometry), `buildGalleryBrushes` (eight states of the popup), `BrushThumbnailSource` (slice 5.22).

## What the captures show (viewed)
`brush-live-open-{dark,light}.png`: the popup around the pointer over the viewport, search field with caret, chips with All selected, the Recent row (Clay, Blob, Trim) above "All brushes", favourites first (Pinch, Smooth with stars), the active brush Clay outlined in accent and highlighted, coloured pictures, letter badges (PI, SM, B, CLAY with the Enter symbol, CLAYB, CR, D), footer with the hint, the brush count and the ticked option. `brush-live-typed-s`: four tiles, each badge "S" dim plus the next letter in an accent pill (M, L, N, T), the Recent section gone. `brush-live-typed-cl`: Clay (exact, Enter symbol) before Clay Buildup (badge CL A). `brush-live-assign`: the popover over the grid with the big S and "4 other brushes start with S: typing it lists 5. Enter assigns anyway." `brush-gallery-{dark,light}.png`: all eight states with icon tiles, the tile menu and the empty state.

Defects found by the captures and fixed: a stale "All brushes" header after the Recent section disappeared (the layout kept the second section), a star overlapping a long badge (the star moved to the lower right of the picture), a hint line cut by an ellipsis (the footer wraps over two lines).
