# Slice evidence: 5.22 Brush library: pictures, categories, search, favourites, recents, letter assignment, settings, documentation

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** Medium (reuses the asset browser's picture machinery; new file format already covered by 5.20)   **Review:** none yet

## Built
- `BrushThumbnailSource` (`source/ui-widgets/.../brushes/BrushThumbnails.*`): the asset browser's `ThumbnailProvider`, `ThumbnailTextureSink`, LRU `ThumbnailCache` and `ThumbnailScheduler` wrapped for the library: bounded by 1024 pictures and 64 MiB, visible tiles first, two rows of margin, 2.5 ms and at most 16 pictures per paint (the first frame shows icons, the pictures follow), Pending until `notifyReady`, Failed keeps the icon until `invalidate`, the cache lives in the controller so reopening is instant. The popup pumps at the start of its paint (before it draws), so a texture is never evicted under a frame that reads it.
- In the popup (slice 5.21 file set): category chips (All plus the host's categories, scrolled with the wheel or Ctrl+Left/Right), the search field with both modes, the favourite star (click or Ctrl+F), the Recent row (up to 8), the Assign letter popover with conflict feedback (how many other brushes start with the letter) and the tile menu (Pick, favourite, Assign letter, Clear letter), the footer with the key hints (wrapped over two lines) and the persisted Pick on unique match option.
- Settings persistence: `BrushStateStorage` (favourites, recents, letters, the option); the preview stores them in `%LOCALAPPDATA%\R1GUI\preview\brushes.json`.
- Documentation: `docs/dev/brush-library.md` (behaviour, algorithm, decisions, API, key flow, pictures, file, tests, limits).

## Gaps
- "Customize order" of the slice title is only partly there: favourites pin first and recents come first, the rest is alphabetical; there is no way to drag brushes into an order of one's own (not in the brief of this batch).
- A provider that stays Pending without telling the source keeps the popup asking for frames (documented); the sample provider is synchronous.
- Favourite stars use the icon set's outline star.
- A narrow popup (a small floating window) shows the option only: no key hints and no count; the notice of the last action is not shown there.
