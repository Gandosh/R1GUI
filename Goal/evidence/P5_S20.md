# Slice evidence: 5.20 Brush library model (headless)

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** Medium (new public API, serialization format, no concurrency)   **Review:** none yet

All GPU work of the slice group ran on the RTX 4080; the RTX 3090 was never selected (`R1UI_GPU=RTX 4080` in `tools/build/env.local.cmd`; `nvidia-smi` shows no process of ours on GPU-7b76b9f0...).

## Built
`source/ui-commands/{include/r1ui/commands,src}/brushes/`: `BrushLetters` (UTF-8 decoding that never fails, simple folding, key characters, keys of names), `BrushLibraryModel` (host brushes sanitised at the boundary, favourites, recents of at most 8, user letter overrides, picture keys, change notification), `query()` (the quick letter algorithm: typed prefix, ordered tiles with next-letter hints, search anywhere, Recent section, categories, dimming variant) and `conflicts()`, `BrushState` (versioned JSON of favourites, recents, letters and the pick-on-unique option, strict parse, atomic store through `customize::TextStore`, corrupt file moved aside, `BrushStateStorage` autosave). Behaviour decisions where the brief was open are in `docs/dev/brush-library.md` section 4.
