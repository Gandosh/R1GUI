# Slice evidence: 4.1 Button, icon button, label

**Status:** TECHNICAL PASS   **Date:** 2026-10-09   **Risk tier:** Medium   **Review:** no independent code review of the widget library yet

Detailed per-reference numbers, commands and unverified items: [P4_g1_notes.md](P4_g1_notes.md). Method: unit tests (fast tier), offscreen visual tests against the OpenPencil reference crops in both themes through the shared harness (GPU tier), a gallery render, all on the RTX 4080 after the owner's GPU rule.

## Built
Button (tones ghost, accent, panel, panelAccent, neutral; sizes sm, md, icon, iconSm; leading and trailing icons), IconButton (sm 20, md 26, active, disabled) and the shared Pressable base; Label is the foundation template widget. Click fires on release inside, Space and Enter on key-up, focus ring for keyboard focus only.

## Visual result
Share, text-button, accent and disabled-accent crops pass the text profile in both themes (0.0 to 1.7% failing before the profile change); icon-button panel, section add and add-stop crops pass; the small icon button, variable trigger and dialog close crops were the misses and pass under the adopted icons profile.
