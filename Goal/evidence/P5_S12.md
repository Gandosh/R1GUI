# Slice evidence: 5.12 Preview: sample editor with rearrangeable panels, floating windows, user-built menus, reloadable layouts

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** High (lifetime, multi-window, serialization)   **Review:** no independent code review of Phase 5 yet

All GPU work ran on the RTX 4080.

## Built
The Editor screen is the preview default: 9 panels, native floating windows, about 45 commands, shortcut editor, customizable menu bar and toolbar, named layouts with restore on startup, theme toggle; AppLoop drives all windows. Owner checklist: docs/dev/preview.md. Perf: docs/perf/phase5_baseline.md.

## Verification
Real-desktop drive on the release and Debug executables, 0 failures; idle CPU 0.00 percent with one native window; frame cost median 0.78 ms (redraw) and 1.22 ms (full relayout); 134 MiB working set, 159 MiB with a native window; startup 1.1 s.

## Not implemented / gaps
The viewport is a flat placeholder; assets have no thumbnails; floating windows stay open when another screen is shown; on the Editor screen the plain-letter global keys (T, Tab, Esc) do not apply, use Ctrl+Q; the Shortcuts tab is cramped in its default region.
