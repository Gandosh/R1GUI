**Status:** TECHNICAL PASS   **Date:** 2026-10-09   **Risk tier:** Low

## Output
`docs/perf/phase3_baseline.json` and `.md`, produced by `r1gui-preview --bench <dir>` (RelWithDebInfo, RTX 3090 via `R1UI_GPU`, validation off, FIFO present, 1440x900, Widgets mode). Machine: AMD Threadripper 2990WX (64 logical processors), Windows 10 Pro for Workstations build 26200. These numbers are a baseline for later regression checks, not budgets.

| Startup, constructor to first frame | 1338 ms (process creation to first frame 1406 ms) |

## Verification
- The builder ran the benchmark once. I re-ran `r1gui-preview --bench` on the merged tree: it exited 0 and its layout (0.0038 ms) and paint-build (0.1587 ms) medians match the recorded values.
- Idle blocking works: the UI loop waits for events instead of spinning; caret blink is a scheduled wake-up (and is the only reason to draw when a text field has focus).
- While minimized the process used 0.016 s of CPU over 3 s.

## Not verified / notes
- The remaining 0.47% idle CPU is probably driver or background threads; not investigated.
- Private bytes stay about 7.6 MiB above the post-settle value after leaving and re-entering the Widgets mode; not investigated.
- GPU memory uses the budget extension only (no own-allocation fallback). Startup time includes first-run font and atlas work and was measured once.
- Numbers are for one machine and one GPU (3090); the 4080 was not measured.
