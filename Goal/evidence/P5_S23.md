**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** High (key flow of every window, lifetime across native windows, files)   **Review:** none yet

All GPU work ran on the RTX 4080; `nvidia-smi --query-compute-apps` lists the preview's pid only on the 4080 UUID (GPU-b959ab15...), never on GPU-7b76b9f0... (the RTX 3090), checked by the drive.

## Built
`examples/preview/editor`: `EditorBrushes.{h,cpp}` (40 generic sculpt-style brushes in six categories, procedural pictures: soft falloff, disc, ring, 3x3 dots, stroke, hatching, dot in ring, wedge, tinted by category; nothing copied), `EditorBrushLibrary.cpp` (controller wiring, `brushes.json`, active brush at start = last pick else Standard, `selectBrush`), changes in `EditorApp` (key taps for the main window and every native window context, status line right part `Brush: <name>`, save), `EditorViewport` (label with the brush and its size, a cursor ring that follows the pointer, Ctrl + wheel resizes it), `EditorMenus` (Tools > Brush library, a toolbar button), `EditorModel` (brush name and size), `PreviewApp` (the GPU texture sink for the pictures), `Shots` (`--shot` renders the library open and after typing S), `GalleryApp` (page 14, Brushes), `DriveStatus` (the library's state and the rectangles of its parts and fully visible tiles). Owner checklist: `docs/dev/preview.md` item 14. `tests/preview/brush_drive.ps1`: the real-desktop drive.

## What the captures show (viewed)
`01_open`: the popup around the pointer over the viewport (40 tiles with pictures, letter badges such as PI, SM, STAM, STAN, SMOOTH with the Enter symbol, the active brush outlined and highlighted, the footer with the hint on two lines, the brush count and the option); `02_typed_s`: ten brushes, dim S plus the next letter in an accent pill (C, L, M, N, O, T, U), Standard and Stamp share T so their pill is outlined only; `07_menu`: the tile menu (Pick, Add to favourites, Assign letter) above the Recent row; `08_assign`: the popover with the large X and "X is free: typing it picks this brush at once. Enter assigns."; `09_float`: the library inside the 244 px wide floating Outliner window (compact mode switch, two columns, option only in the footer); `11_restarted`: after the restart the Recent row (Inflate, Blob, Clay Tubes, Elastic Grab, Snake Hook), the favourite star on Dam Standard, the status line `Brush: Inflate`, the viewport label `brush: Inflate (size 48)`.

## Deviations and gaps
- The first opening of a session costs about 21 ms offscreen (glyphs, icons and the first 16 pictures are made then); later openings under 1 ms. On the real desktop the key to pixel time was 11 to 12 ms (with the first opening of the drive at 23 ms), which includes the display refresh.
- The Assets grid and the Actions list keep plain letters for their type-ahead, so B typed while they have the focus does not open the library (click the viewport or the Outliner first); documented in `docs/dev/brush-library.md` section 4.
- A popup in a very small floating window shows no key hints and no count (only the option).
- Not verified: another display scale, an IME, a keyboard layout whose B key produces a different character.
