# Slice evidence: 2.13 Unreal reference reads via a separate reader session

**Status:** TECHNICAL PASS (publication of the specs is an open owner decision)   **Date:** 2026-10-09   **Risk tier:** High (licensing)

## What was done
- Owner cleared reading the reference source in slice 0.1. The installed Unreal Engine 5.7 (`E:/UE_5.7`, source under `Engine/Source`) was read by five separate reader sessions, one per group of specs: (1) focus, shortcuts, commands; (2) docking, layouts, resize; (3) floating windows, popups and menus; (4) customization, drag and drop, selection; (5) property editing and undo, curve editor, asset browser.
- Each reader wrote behavior-only specs (no code, identifiers, file names, quoted strings or structure) from the user's point of view, with numbers labelled read or inferred. No reader edited anything else.
- Implementation work (the docking sandbox, slice 2.14) used only the specs and was told not to read any reference source.
