# Slice evidence: 4.16 Widgets pass the visual comparison and match the interaction specs

**Status:** TECHNICAL PASS (tolerances adopted by the owner; known 1 px differences)   **Date:** 2026-10-09   **Risk tier:** Medium   **Review:** no independent code review of the widget library yet

Detailed per-reference numbers, commands and unverified items: [P4_calibration_notes.md](P4_calibration_notes.md). Method: unit tests (fast tier), offscreen visual tests against the OpenPencil reference crops in both themes through the shared harness (GPU tier), a gallery render, all on the RTX 4080 after the owner's GPU rule.

## Built
Text emboldening is now a continuous function of text luminance and weight class fitted on 40 reference samples; the checkbox check mark, apply-variable icon and tolerance profiles were calibrated; the owner accepted the proposed profiles as they are.

## Visual result
Under the adopted profiles all 300 visual comparisons pass (57 of 57 GPU tests); under the previous provisional profiles 42 of 300 failed. Ink ratios ours/reference for bright regular text on dark went from 0.72 to 0.81 to 0.96 to 1.06.

## Not implemented / gaps
Remaining visible differences: about 1 px text or icon position offsets (tooltip box width, toast text, flyout and menu bar text, dialog close X at a fractional position), dark text on light is 1 to 8% heavy, reference LCD text colour fringes (compared on luminance).
