# Slice evidence: 3.10 ui-theme: tokens.json loader and style resolution

**Status:** TECHNICAL PASS   **Date:** 2026-10-09   **Risk tier:** Low   **Review:** no independent review yet (recommended at phase close)

## Built
- Typed access to all token sections (space, radius, font sizes, line heights, weights, shadow layers, motion, widget metrics) with validation of present sections, dark and light switching without reload and a revision counter, and a StyleSheet that maps a style key plus state flags (hover, active, focus, disabled, selected, mixed, bound; a disabled widget ignores hover and active) to a resolved style from a token-reference table (panel.background, panel.section, field.panel, button.ghost, button.accent); a bad row rejects the whole table and lists every error.

## Verification
- The ui-theme tests load the real assets/theme/tokens.json and assert space.control 26, radius.panel 4, the shadow lg layers, dark panel #2a2a2a and light panel #ffffff, plus hostile token files (missing sections, wrong types, NaN, negative sizes, unknown keys ignored).

## Not verified and gaps
- OpenPencil never defines the colours its widget code calls danger, primary and border-strong; the style table does not resolve them yet (decided with the first widget that needs them in Phase 4).
