# Slice evidence: 0.4 Decide windowing layer

**Status:** OWNER ACCEPTED
**Date:** 2026-10-09   **Risk tier:** Medium (shapes the platform layer and every window/input path)   **Review:** none (owner decision)

## Decision
Own Win32 platform code behind a thin, replaceable `ui-platform` interface. No SDL3 or GLFW.

## Options considered
| Option | License | Note |
|---|---|---|
| Own Win32 | none (ours) | Full control of native floating panels, cross-monitor dragging, per-monitor DPI, pen pressure/tilt, custom title bars. Chosen. |
| SDL3 | zlib | Cross-platform from day one; less control over multi-window dragging, custom title bars, pen details. |
| GLFW | zlib | Weaker multi-window, DPI and pen support than SDL3. |

## Consequences
- `ui-platform` exposes an interface the rest of the toolkit uses; no Win32 types leak into other modules.
- macOS and possible Linux backends are written ourselves after the first release (cost accepted by owner).
- Slice 3.1 implements the Win32 backend; slice 2.3 specs floating panels, multi-monitor and DPI behavior.
