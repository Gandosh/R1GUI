# Slice evidence: 5.17 Create Custom Menu window and the Custom Menus top-level menu

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** High (new public widgets, drag and drop, lifetime)   **Review:** none yet

All GPU work ran on the RTX 4080.

## Built
Owner requirement 2026-10-10: the Customize mode is replaced by a window. `source/ui-widgets/.../custommenu/creator`: `CreateCustomMenuWindow` (type chooser, then pie or panel editor on the left, the `ActionList` on the right, name, validation message, Create/Save, Cancel, Save to file, Load from file), `PiePreviewEditor` (the real `PieMenu` drawing plus slot outlines, drop highlight, selection, swap by dragging, clear by key or context menu, 4/6/8 slots), `PanelPreviewEditor` (the button grid with columns, button size and labels, drop-before/after, move by dragging or Ctrl+arrows, remove), `CreatorSession` (the draft and chosen type outliving the widget), `GalleryCreator`; the headless `MenuDraft` in `ui-commands`. The window opens as a **native floating window** (a dock panel floated at 1080 x 700); Custom Menus > Create Custom Menu... starts a new draft, the Edit... entries open the same window filled in. **Decision (documented in the window header and docs/dev/custom-menus.md): edits are applied on Create/Save to a working copy, Cancel discards it, so nothing needs reverting.** Entries can get their own label. The Edit > Customize command, the Quick Actions panel and the Customize tool strip are gone from the Editor (the customize library is untouched); the four `customize.*` commands the controller registers are removed from the registry so they do not clutter the action lists. Decision on the old command palette panel: replaced by the **Actions** panel (same commands, with descriptions, searchable), the palette's only extra (dragging into menus in edit mode) is unreachable now.

## Not implemented / gaps
Closing the creator with the window's X discards the draft; no undo inside the creator; entry icons cannot be chosen (the command's icon is used); the creator is not available as a docked panel by design (it can be docked but is meant to float).
