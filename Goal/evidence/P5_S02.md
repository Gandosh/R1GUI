# Slice evidence: 5.2 Floating panels as native windows with rounded corners

**Status:** TECHNICAL PASS (owner interaction pending)   **Date:** 2026-10-10   **Risk tier:** High (lifetime, multi-window, serialization)   **Review:** no independent code review of Phase 5 yet

All GPU work ran on the RTX 4080.

## Built
NativeFloatingBackend: borderless owned tool windows, DWM round corners, per-window UiContext, WindowTarget and atlas consumer, toolkit-drawn 34 px title bar, AppLoop multi-window loop, cross-window tab drag with pointer tracking and stacking-aware drop queries, DPI and display-change handling. Detail: docs/dev/native-windows.md.

## Verification
Full backend conformance suite on real windows (every optional clause ran), dock integration tests with synthetic input, 31 of 31 checks in the real-desktop drive (tab out, move, resize, dock back, cross-window drop, close, minimize and restore, second monitor), Debug validation layer clean, USER/GDI handle counts stable over 40 create/destroy cycles.

## Not implemented / gaps
Per-window full screen not implemented; no minimize button on floating windows; popups are clipped to their window. Unverified: a real scale change between monitors (both monitors are 100 percent), snap layouts, DWM shadow, a real display-change event.
