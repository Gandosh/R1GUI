# Slice evidence: 4.3 Number field with scrubbing

**Status:** TECHNICAL PASS   **Date:** 2026-10-09   **Risk tier:** Medium   **Review:** no independent code review of the widget library yet

Detailed per-reference numbers, commands and unverified items: [P4_g2_notes.md](P4_g2_notes.md). Method: unit tests (fast tier), offscreen visual tests against the OpenPencil reference crops in both themes through the shared harness (GPU tier), a gallery render, all on the RTX 4080 after the owner's GPU rule.

## Built
NumberField with leading glyph, value, suffix, mixed display, drag scrubbing (Shift fine, Ctrl coarse, a 100 px drag moves the value by step x soft range span), edit mode, arrow-key stepping, clamps, expression and unit parsing, begin/end interaction callbacks for undo grouping, tabular digits to match the reference.

## Visual result
x, width, opacity, mixed, bound and edit-mode crops pass in both themes (0.1 to 1.5% failing).

## Not implemented / gaps
No pointer hiding while scrubbing (host restore-position callback), no non-linear scrub response, no selection auto-scroll with a still pointer.
