# Slice evidence: 3.9 ui-core: invalidation, redraw only what changed

**Status:** TECHNICAL PASS   **Date:** 2026-10-09   **Risk tier:** Medium   **Review:** no independent review yet (recommended at phase close)

## Built
- Invalidator with layout-dirty and paint-dirty propagation, relayout boundaries (fixed-size, previously laid out widgets stop upward propagation; clean subtrees of unchanged size are skipped), a damage list in absolute coordinates (covered rectangles dropped, cheapest pair merged beyond 8), needsFrame and takeDamage, idle detection, animation tick requests. A viewport change, a first layout or a full-layout request forces a whole pass.

## Verification
- ui-core.invalidation: 98 checks: a leaf's paint change damages exactly its absolute bounds; a fixed-size child's change does not relayout siblings; an idle UI reports no frame; the merge limit; reparenting damages both old and new places.
